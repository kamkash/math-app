# Rust Tauri based desktop and mobile symbolic math app 
## Planned features:
    1. Symbolic algebra, calculus, linear algebra, statistics solver
    2. Math notes style UI with plots and charts
    3. antlr grammar based parser generator and evaluator
    4. Use rust-antlr parser generator
    5. Use symengine-rs Rust bindings for C++ symengine
    6. llama.cpp based gguf model inference (math solver)
    7. AI based OCR image to math LaTex generator for handwriting recognition
